# Contributing

Project Ganymede welcomes noncommercial improvements, especially clearer explanations, accessibility fixes, new recorded demonstrations, and better ways to make uncertainty visible.

Before opening a pull request:

1. Open an issue describing the problem or demonstration you want to add.
2. Keep examples fictional, public-domain, or supported by sources you have permission to redistribute.
3. Run `npm run check`.
4. Explain what a visitor will understand more clearly after the change.

By contributing, you agree that your contribution is distributed under the repository's PolyForm Noncommercial License 1.0.0.
