# 9D-Chess Showcase Website Blueprint

## The Goal
A jaw-dropping, interactive portfolio website designed to serve as a "Museum Exhibit" for the 9D Strategic Physics Engine. This will be handed off to a coding agent for React execution.

## User Journey & Layout Structure

### Phase 1: The Hook (The Docent)
* **Content:** NotebookLM Studio generated audio/video.
* **Purpose:** Acts as the "docent" of the museum. It breaks down the high-level concepts of the 9D framework (e.g., the FBA case study) in a digestible, narrative format so the viewer understands the stakes before interacting.

### Phase 2: The Sandbox (Interactive 3D Visualizer)
* **Content:** React-based interactive 3D component embedded directly below the video.
* **Aesthetic:** Clean, highly accessible, modern analytical UI. Enterprise data clarity over vaporwave/cyberpunk aesthetics.

#### Sandbox Exhibit A: The FBA Cyborg Sourcing Trap
* **Interactive Elements:** 'Competitor Algorithm Rigidity' slider, 'Bait Price Drop' slider.
* **Visual Behavior:** A 3D topological grid where the user triggers a "Margin-Squeeze Gravity Well." The rigid competitor algorithm is violently pulled down into the well, locking into a negative true-profitability state while the attacker escapes.
