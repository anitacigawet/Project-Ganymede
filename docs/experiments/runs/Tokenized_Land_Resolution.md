### Master Silo approach (variant from Powell)

Powell used 4 separate persona-locked Oracle notebooks. For this run the user (NotebookLM Pro subscriber) consolidated to a **single Master Silo** with the same PKI persona and ran all four research questions sequentially inside it. The user's reasoning: *"It allows the AI to see the inter-connections between the IMF debt and the land law in real-time before it even reaches the Umpire."*

Tradeoffs vs. multi-silo:
- **Pro**: cross-research synthesis happens inside the silo, faster end-to-end, less coordination overhead.
- **Con**: harder to audit which fact came from which research pass; if one research question contaminates another's framing, you can't easily isolate it.

This is now an established methodology variant. Either approach is valid; multi-silo is the default for higher-stakes runs where citation provenance matters.
