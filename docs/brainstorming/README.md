# Brainstorming

Ideas surfaced during the architecture conversation that are interesting enough to preserve but **not committed to**. None of these are roadmap items. They are riffs the user wanted to keep visible without locking in. Each entry has been mined from the original session, de-fluffed, and noted with the framing context — particularly where the dramatic vocabulary needs nuance.

The user's standing instruction on tone: *"You will have to have nuance when reading those things from Gemini, not with the 9D-Chess foundation. Apply nuance to Project Ganymede / Gemini-brainstormed material — but don't discount it. Some of these ideas are genuinely interesting."*

## What's NOT in this folder

- **Productization paths** (Museum, Sandbox, SaaS, Blind-Spot Auditor, AI Mediator, Strategic Alpha Hunter) — those live in [`../visions/`](../visions/) because they are formal blueprints rather than riffs.
- **Active research lines** — those live in [`../experiments/pathways/`](../experiments/pathways/).
- **Tactical methods that became standard practice** (Genie Prime, Dream State Protocol, Nuance Prime, Iterative Engine) — those live in [`../protocols/`](../protocols/), [`../concepts/`](../concepts/), and [`../experiments/pathways/`](../experiments/pathways/).

## How to use what's here

When the project is looking for a new scenario to test a pathway against, this folder is the menu. Most of these ideas have not been *run* — they exist as scenario seeds. Pick one, frame it as a Wish or as a Cleanroom scenario, and run the appropriate pathway against it.

When you find an idea here genuinely worth promoting, copy/move it to the appropriate non-brainstorming folder and update its status. Brainstorming should remain the bench, not the field.

## A note on the user's standing instruction for these scenarios

The user has explicitly told the project that the specific real-world targets occasionally referenced in the active pathway docs (Save Mohave water rights, Amazon FBA decisions, etc.) **are illustrative examples, not real candidate runs**. The user's framing: *"these are just examples of potential applications I could use for that … those are just kind of like things that I brainstormed with the AI. Those are not actually things I wanted to create."*

Similarly, the **autonomous-scouting Genie variant** described in [`../experiments/pathways/genie_protocol.md`](../experiments/pathways/genie_protocol.md#variant-autonomous-scouting-brainstorming-tier-not-committed-work) is brainstorming-tier, not committed work. The user's later clarification: *"that's not an actual thing; that's just one of those experiment brainstorming things."*

Treat all of this as *menu, not roadmap*. The four real silos of the project are documented in [`../OVERVIEW.md`](../OVERVIEW.md#the-four-silos-canonical-project-organization) — Predictor, Envisioner, Methodology, Pluggable. Items in this folder are sub-items inside those silos, not silos themselves.
